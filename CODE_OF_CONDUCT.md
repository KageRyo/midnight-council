# Code of Conduct

Midnight Council aims to be a constructive and welcoming project for contributors, reviewers, and players.

## Expected behavior

- Be respectful, patient, and specific when discussing code or game design.
- Assume good intent while still addressing harmful behavior clearly.
- Keep feedback focused on the work, and explain the reasoning behind requested changes.
- Protect private information, credentials, reconnect tokens, and deployment details.

## Unacceptable behavior

Harassment, discrimination, threats, intimidation, doxxing, sexualized or hateful conduct, deliberate disruption, and public disclosure of private or security-sensitive information are not acceptable.

## Enforcement and reporting

Maintainers may edit or remove content, close discussions, restrict participation, or take other action needed to keep the project safe and productive. Report conduct concerns privately to the repository maintainers through GitHub. Use [`SECURITY.md`](SECURITY.md) for security vulnerabilities rather than a public report.

This policy applies to issues, pull requests, code, documentation, discussions, and project-related deployments.
